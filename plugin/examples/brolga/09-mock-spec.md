# Mock spec: Swell 3 product page, phone (390 × 844)

Written before the build from the evidence: the live page and `02-capture-live-values.md` (17 Nov 2026), the sweep note, the report's evidence crops, and the benchmark and cross-check screenshots. One row per change; **anything not in this table stays as the live page.** Red numbers are report findings; there are no D (design-judgement) rows in this version. **Approved 17 Nov 2026 with three changes (applied below).**

**The decision the screen is organised around:** "Is this shoe right for my foot — which width, which size — and is it safe to buy from a brand I don't know?" The proposed page keeps the live order (gallery → name and price → 足幅 → カラー → サイズ → button → service list) and puts the answers inside that order rather than below it.

**State shown:** a runner arriving from the wide list (`/shoes/?width=wide`), so ワイド is selected; ショアライン; 27.0 selected so the sticky bar's selected state is visible. Current side: a fresh capture of the same page in mobile emulation, as a first visit, with the welcome sheet and the sticky bar behaving as they do live.
